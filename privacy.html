Privacy policy.隐私政策。

How coinfin.fun handles data: the short version is that it is a static read-only site and collects almost nothing.coinfin.fun 如何处理数据:简短版本是,这是一个静态只读网站,几乎不收集任何数据。

Data we collect我们收集的数据

Almost none. This is a static, read-only website with no accounts, no sign-up and no analytics trackers. Your language choice is stored in your own browser (localStorage, key cf-lang) so the site remembers it; nothing about that choice is sent anywhere.

几乎没有。本站是静态只读网站,无账户、无注册、无分析跟踪器。你的语言选择保存在你自己的浏览器中(localStorage,键 cf-lang)以便本站记住;该选择不会发送到任何地方。

On-chain data链上数据

When the site reads contract state, your browser sends read requests to public BNB Chain RPC endpoints; those providers can see your IP address and the data requested, under their own policies. Everything the checker displays comes from public blockchain records. Wallet addresses and transactions on BNB Chain are public by design.

Third parties第三方

Fonts load from Google Fonts, which receives a standard web request when a page loads. Outbound links (PancakeSwap, BscScan, X) lead to third-party services with their own privacy policies. The project never sells personal data, because it does not collect any.
