CoinFin Curve is a launchpad on BNB Chain where new tokens are sold on bonding curves that only Binance Agent ID holders can access before graduation. It is a relaunch of coinfin.fun: the earlier share-mining model is retired, and the existing FIN token carries over as the Pass claim and liquidity token of the new floor.CoinFin Curve 是 BNB 链上的发行平台,新代币在联合曲线上出售,毕业前只有币安 Agent ID 持有者可以进入。它是 coinfin.fun 的重启:旧的份额挖矿模型退役,现有 FIN 代币延续下来,作为新大厅的 Pass 领取与流动性代币。

Three choices define the design. Identity first: the Agent ID gate and per-wallet caps keep a launch lane that scripts cannot flood. Open splits: the 5% curve tax divides between creator, platform and Pass holders inside the same transaction, on the record. A Pass that pays: instead of a collectible with promises, the CoinFin Pass is a working key that widens caps, earns BNB season dividends and claims FIN.三个选择定义了这个设计。身份优先:Agent ID 门槛和每钱包上限保持一条脚本无法淹没的发行通道。公开分配:5% 曲线税在同一笔交易内分给创建者、平台和 Pass 持有者,有链上记录。一张会付钱的 Pass:CoinFin Pass 不是只有承诺的收藏品,而是一把能用的钥匙,提高上限、赚取 BNB 季度分红并领取 FIN。
